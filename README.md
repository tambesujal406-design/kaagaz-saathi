# Kaagaz Saathi

Live demo: https://tambesujal406-design.github.io/kaagaz-saathi/

A learning website for first-time users of DigiLocker, Aadhaar and PAN services, with step-by-step guides and a progress checklist.
It also covers fraud-prevention habits, fixes for common problems, a glossary and a five-question quiz.

Built with HTML, CSS and JavaScript.
